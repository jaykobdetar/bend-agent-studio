# Seven toy-text benchmarks

These checked-in [finite-world definitions](../../../worlds/benchmarks/toy-text) are usable by the Node runner and the optional Gymnasium adapter. Python/Gymnasium is required only to regenerate/compare them. Use the [benchmark table](../../../EXPERIMENTS.md#benchmark-worlds) for world names, horizons and scores.

## Reproduce

Use Node 24+, Bend 2.0.40, and the [adapter's pinned optional Python environment](../README.md). From the repository root:

    node integrations/gymnasium/toy_text/oracles.mjs
    node experiment.mjs run experiments/toy-text.json runs/toy-text
    node experiment.mjs verify runs/toy-text

With that Python environment active, from `integrations/gymnasium`:

    python toy_text/generate.py --check   # compare regenerated bytes
    python -m unittest -v toy_text.test_ports

To intentionally regenerate, omit `--check`, then run `node toy_text/oracles.mjs --write` from that same folder and review the data diff. The [source](https://github.com/Farama-Foundation/Gymnasium/tree/v1.4.0/gymnasium/envs/toy_text) is Farama Foundation's Gymnasium 1.4.0 ([MIT license](https://github.com/Farama-Foundation/Gymnasium/blob/v1.4.0/LICENSE)); generation refuses other versions.

## What matches

* **Lakes, Taxi, Cliff:** Take every official state/action row in `env.unwrapped.P`, including wall bumps, blocked pickups/dropoffs and otherwise unreachable rows. At a terminating edge the Bend destination is a terminal clone with the original public observation. At an open state all Gym action IDs remain available. The Taxi action mask in Gym is an optional suggestion; it does not prohibit actions. The source's floating probabilities are rationalized to their intended simple fractions (including the three equiprobable slide directions). Authored weights match those fractions exactly; tests enumerate reset distributions and every joint (next observation, integer reward, termination) distribution.
* **Sampling precision:** Bend's existing integer sampler partitions a single 32-bit word by flooring cumulative weight fractions. Neither 1/3 in slippery Lakes nor 1/300 on Taxi reset can equal an integer multiple of 2^-32. In a three-way slide, two intervals contain 1,431,655,765 words apiece and one contains 1,431,655,766. Each elementary interval differs from the intended probability by less than 2^-32; coincident destinations sum their elementary probabilities. Deterministic transitions match even after compilation. Tests compare actual compiled integer intervals as fractions, not only input weights. Different Gym and Bend random generators are **not** seed-by-seed trajectory equivalents.
* **Blackjack:** The official default spec is `sab=True, natural=False`. Cards are drawn with replacement; a ten-valued card has probability 4/13. The hidden natural flag distinguishes an initial ace/ten from a later soft 21. An independent dealer hole card and subsequent draws to 17 (including soft 17) are marginalized when the player sticks. Public observation is the injective encoding `(player_total * 16 + dealer_upcard) * 2 + usable_ace`; IDs 0 and 1 mean stick and hit. Standing/busting preserves the public terminal observation. No extra dealer steps are exposed. If a rational stick distribution needs a denominator above the format's weight limit, the exporter floors its cumulative endpoints directly to the same 32-bit grid. No ideal infinite-precision or RNG-stream parity is claimed.
* **Blackjack behavioral cross-check:** The test solves the compiled kernel backward and asserts the greedy action agrees across all reachable hidden states sharing a public observation. Neither simulator reveals the natural flag to this policy. Over 25,000 episodes each (seeds 20261118 onward), the Gym mean was −0.046760 (SE 0.006017), Bend adapter mean −0.039600 (SE 0.006025), and the finite oracle −0.043113. Each estimate is within one standard error of the oracle; the seeded regression uses a four-SE tolerance. This is an aggregate behavioral test, not exhaustive independent validation of every Blackjack row.

## Compiled-run coverage

The two-world Lake 4×4 plan completed all eight trials and verified its 24 checkpoints with Bend 2.0.40. Separate one-trial short-horizon plans compiled, ran and verified for Lake 8×8 (both variants) and CliffWalking. Taxi and Blackjack now use a compact generated Bend layout. Separate two-arm studies completed at their published horizons (200 and 32); archived reruns reproduced every checkpoint byte and a frozen test trajectory per world. Three matched short-horizon builds per world completed at sampled peaks of 371–404 MiB, whereas all six legacy builds crossed a 1,200 MiB guard. See the [measurement method, limits and parity tests](../../../tools/finite-layout/README.md). This does not claim equivalent Gym/Bend random streams or unrestricted compiler peak memory.
